# Live Site SYNC Rebuild Plan

Status: stacked candidate planning artifact
Depends on: asset continuity candidate branch `feat/asset-continuity-sync-v1`

## Goal
Rebuild the Live Site home surface so it reads as an arena pressure-party product before any copy is read, while preserving all multiplayer authority and existing game-state behavior.

## Canonical direction
- electric blue / cyan / magenta arena world
- oversized metallic / neon SYNC wordmark treatment
- visible social/player energy, not a SaaS dashboard
- pressure cues: timer ring, lock state, mode ticket, synchronized reveal language
- five modes remain legible without becoming the visual hero
- layered foreground / midground / background depth
- moving beams, scanner sweeps, restrained crowd light, reveal particles

## Non-goals
- no gameplay contract changes
- no Durable Object changes
- no room/token/privacy changes
- no new analytics authority
- no deployment or production claim

## Truth boundary
The approved external arena reference remains canonical. This rebuild can improve structural fidelity and remove generic-template drift, but cannot claim full source-to-render artistic fidelity until the canonical visual artifact is available to the runtime/reviewer for direct comparison.
