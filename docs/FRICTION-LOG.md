# Amazon Developer Friction Log

Record only genuine friction encountered while building. The goal is actionable product feedback, not manufacturing complaints.

## Entry template

### FRIC-000

- Date/time:
- Exact commit SHA:
- Amazon product / SDK / tool / documentation surface:
- Environment / device / simulator:
- Goal:
- Expected behavior:
- Actual behavior:
- Reproduction steps:
- Frequency:
- Severity: blocker / high / medium / low
- Evidence: log / screenshot / trace / minimal reproduction
- Workaround attempted:
- Workaround result:
- Suggested improvement:
- Feedback submitted where / when:
- Status: OPEN / WORKAROUND / RESOLVED / NOT-REPRODUCIBLE

## Integrity rules

- Preserve exact error text where legally/safely shareable.
- Redact credentials and private data.
- Do not inflate severity.
- Separate Amazon friction from bugs caused by our own code.
- If attribution is uncertain, mark it uncertain.
