## Source of truth

For SYNC implementation truth, authority is ordered as follows:

1. exact deployed runtime evidence and real-path browser proof
2. the authoritative `jussray/sync-party-game` source at an exact SHA
3. current continuity/control-room receipts and fingerprints
4. older documentation or chat context
5. inference

Do not build forward from a known bad, stale, failing, or unverified state. Repair or revert it first, prove the repaired path, then continue.

## Product boundary

SYNC has independent presentation surfaces, but one authoritative multiplayer game contract. The Durable Object game state remains gameplay authority. The SYNC Control Room is observational and must not become a gameplay dependency. Founder Control Room may consume privacy-safe evidence, but that relay grants no implicit gameplay mutation authority.

## Verification

Browser/runtime changes require Playwright evidence. Production claims require the repository's exact-green-SHA promotion and public runtime identity proof.


## Portfolio cinematic composition standard — staged agent instruction

For **authorized** design, coding, review, and visual handoff of any UI, game, website, app, route, or user flow owned here, create **one cohesive cinematic composition**. Use the approved original product artwork and current repository design tokens as the source of truth; wireframes/mockups are not substitutes. Maintain a single intentional scene language for hero, navigation, content, actions, settings, auth, commerce, loading/error, and responsive states where they exist. Keep each product's distinct colors, typography, logos, characters, mood, and voice; never replace them with generic Juss & Co. branding.

Motion, sound, glow, lighting, depth, and transitions must serve the user journey without flashing, forced autoplay, heavy paint cost, inaccessible contrast, blocked focus, or reduced-motion regressions. Preserve existing payment, data, privacy, app-specific, licensing, and release gates. Before a PASS claim require exact-branch/head captures and functional, mobile, keyboard, contrast, reduced-motion and performance verification. State source-authored, tested, visually verified, deployed, and live runtime separately; UNKNOWN is not PASS. No silent repo, provider, publication, spending, merge, or deployment authority.
