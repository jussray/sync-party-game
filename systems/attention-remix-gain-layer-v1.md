# Attention Remix — Gain Layer v1.0

**Author / Owner: Raylene (Ray), Juss & Co.** — originated by Ray's order 2026-11-28: "Implement the fix to gain what we have not." Standing addendum to Attention Remix System v1.0 (~/workspace/goals/social-accounts-and-posting-cadence/files/attention-remix-system-v1.md) — that system names the job; this layer mechanically enforces the mechanic that earns it.

## Why this exists (the diagnosis)

The weekly review (2026-11-28) proved the gap: @jussnco at 289 Views in 7 days — 4.8× the 28-day baseline — with **0 likes, 0 comments, 0 shares, 0 saves, 0 bio taps** all week, and followers moved 16→18 in 25 days. The posts are being *seen*. They are not being *acted on*. Views without actions are a mechanic failure, not a reach failure. This layer adds the conversion mechanics v1.0's jobs assume but never spelled out.

## The laws (implant into every social pipeline, alongside Attention Remix v1.0)

1. **THE MECHANIC RULE.** A post does not end on a question mark — it ends on its mechanic. The job is earned by a built-in device, not by hoping:
   - **SAVE job** = the post carries a screenshot-able end frame (checklist / card / the exact words) held **at least 2 seconds**, and caption line 1 names what the save is *for*: "Save this before your next court date." No end frame, no SAVE job.
   - **SEND job** = the caption names the exact person to send it to: "Send this to the friend who always calls the bluff." A specific person, a specific situation — never "share this," never "tag someone."
   - **COMMENT job** = ask for a *specific small reply* — one word, a number, a 3-word answer — with a promised payoff: the boldest reply gets featured, answered, or run in the next post. Never an open-ended "what do you think?", never "comment YES," never engagement-for-access.
2. **FOLLOW HOOK.** Every post names its season or part and what drops next — "Part 2 tomorrow," "Day 4 of Law of the Day" — so following has a concrete reason attached to a concrete next thing. "Follow for more" is banned as filler.
3. **DOOR LINE.** When the featured project has a live site, one caption line points at it as the door — the post walks them to the site, not just to the next post. This extends the standing engagement→live-sites law to the posts themselves.
4. **FORMAT-FAILURE RULE.** A post sitting at 0 saves + 0 sends + 0 comments after 7 days is a **format** failure, not a topic failure. The topic is not dead — it may return only under a different job and a different mechanic. Never re-run the same topic in the same format and call it a new attempt.

## Measurement (unchanged from v1.0 — now enforced)

Per Reel, in this order: average watch time, likes per reach, sends per reach, saves per reach, % non-follower reach. **Raw views alone never count as a win again.** A week of views with zero actions is a failed week, and the format-failure rule above is what fires.
